Privacy Policy

Effective Date: April 19, 2025

This extension, YouTube Comments Downloader, does not collect, store, or share any personal data from users.

Information Collection and Use

This extension operates entirely within the user's browser and does not transmit any data to external servers. All data (such as YouTube comments or video details) is processed locally and only when initiated by the user via the extension interface.

Permissions

The extension uses the following Chrome permissions:

  • activeTab – to access the content of the YouTube tab when the user activates the extension.
  • scripting – to inject scripts that extract visible video details and comments.

Data Sharing

No user data is shared, sold, or transferred to any third party. The extension does not use analytics or advertising services.
